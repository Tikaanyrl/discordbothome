# Discord Bot Manager

Verwalte deinen Python-Discord-Bot direkt in Home Assistant: Start/Stopp, Editor, Dateien, Live-Logs, Paketinstallation und Sicherungen. Code und Daten bleiben unter `/share/discord-bot-manager/` erhalten. ARM64 und AMD64 werden unterstützt.

Nach der Installation die Weboberfläche öffnen, Token konfigurieren und vorhandene Daten importieren. Details stehen im Reiter Dokumentation.
